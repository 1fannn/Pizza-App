# Pizza App

A React pizza menu for Andy's Pizza Co., built for C304 Lesson 7.

## Live site

[Open Pizza App on Netlify](https://incredible-lokum-03d82a.netlify.app/)

## Features

- Displays six pizzas with photos, ingredients, prices, and sold-out status.
- Shows the shop tagline and Order button during opening hours, from 10:00 a.m. until 10:00 p.m. in the visitor's local time.
- Uses reusable React components and a menu rendered from an array.

## Run locally

From the project folder:

```sh
npm install
npm run dev
```

Run `npm run build` to generate the production site in `dist/`.
